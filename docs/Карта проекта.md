## 7. Как использовать двух агентов без риска

### Можно параллельно

- Codex: данные, API, тесты, миграции, интеграция
- Claude Code: UI/UX, навигация, экраны, read-only QA, отдельные ветки

### Нельзя параллельно

- два агента меняют одну таблицу
- два агента делают migrations
- два агента меняют RLS
- два агента меняют payroll
- два агента меняют clock-in/out
- два агента деплоят
- два агента обновляют этот файл
