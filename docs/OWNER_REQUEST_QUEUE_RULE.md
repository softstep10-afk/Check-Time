# Owner Request Queue Rule

Owner may introduce ideas anytime.

If an idea conflicts with the current safe build order, it is queued instead of executed immediately.

The assistant must:

1. State the current layer.
2. State the request's target layer.
3. Record or update the queue in docs/Карта проекта.md.
4. Return to the current approved task.

No new implementation begins until the current block is DONE.

This rule protects production, RLS, payroll, GPS, storage, client-visible data, Project Finance Folder, Client Portal, estimates, invoices, and AI work from being mixed into the wrong layer.
