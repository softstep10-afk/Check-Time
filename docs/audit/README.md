# 📋 Папка аудита

**Для Андрея:** здесь хранится полный анализ состояния приложения и план починки.

## Что читать

### 🎯 Главный документ
**`AUDIT_REPORT.md`** — полный отчёт: 11 найденных багов, 6 фич-запросов, архитектурные наблюдения, рекомендуемый порядок работ.

### Связанные документы (в корне проекта)
- **`CLAUDE.md`** — Claude Code автоматически читает его при старте сессии. Содержит правила работы и навигацию.
- **`PROGRESS_LOG.md`** — живой журнал: что сделано, что в процессе, что следующее.
- **`HANDOFF.md`** — первое что прочтёт любая новая сессия.

## Как пользоваться

**Если ты открываешь проект после перерыва:**
1. Читай `HANDOFF.md` (1 минута)
2. Потом `PROGRESS_LOG.md` (смотришь последние записи)
3. `AUDIT_REPORT.md` если забыл что не работает

**Если найдёшь новый баг** — говоришь в чате помощнику, он добавляет в `AUDIT_REPORT.md` раздел «Найденные проблемы» и пишет коту короткий промпт на починку.

**Если кот в Claude Code** — он сам прочитает `CLAUDE.md` и будет знать всё.

## Почему появилась эта папка

Проект рос итеративно, контекст расползался по разным `.md` файлам. Аудит 19 апреля 2026 собрал всё в одно место. Идея: любой человек (или новая AI-сессия) за 5 минут входит в проект полностью.
